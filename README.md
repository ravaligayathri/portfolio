# Ravali Kuppachi — Portfolio

A responsive React + Vite portfolio for Ravali Kuppachi, designed to showcase cloud architecture, platform modernization, engineering leadership, and applied AI work.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## GitHub Pages

Create a GitHub repository and push this project to its `main` branch. In the repository settings, choose **Pages → Build and deployment → GitHub Actions**. The included workflow builds and deploys the site on each push to `main`.

The Vite base path is derived automatically from the GitHub repository name during the workflow. Project repositories deploy at `https://USERNAME.github.io/REPOSITORY/`; a repository named `USERNAME.github.io` deploys at `https://USERNAME.github.io/`. Local development uses `/`.
